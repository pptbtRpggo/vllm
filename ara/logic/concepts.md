# 术语

- **SLO**：明确工作负载下的时间门槛T与覆盖要求r，例如至少99%的请求TTFT不超过T；同时注明观察窗口和失败请求处理。
- **门槛来源分位数**：用校准集P95/P85等统计量选取T的方法，不自动定义覆盖要求r。
- **实测TTFT分位数**：本轮请求TTFT分布的统计量，P99/P90场景图应明确展示对应统计指标。
- **stage设备执行区间**：设备起止标记之间的经过时间，可能含stream空档；与算子活跃时间、CPU准备/提交时间及请求TTFT分别记录。
- **NPU event区间**：event之间的设备时间线区间，并不自动等于纯kernel活跃时间。
- **零等待对照**：保留模拟实现所需路径但不追加等待，用于检查插桩、提交和通信载体开销；另外需要无插桩原生路径。
- **软件延迟模拟**：在某条执行路径上增加延迟的模型；精确硬件算力/HBM等效需要独立证据。
- **DP预测最优**：在给定输入成本、约束和目标函数下的最优；与端到端实测全局最优分别验证。
- **闭环负载**：每个并发客户端等完整响应结束再立即补发，输出长度及服务速度会改变后续到达过程。
- **采样层级**：请求、microbatch、layer、rank和服务运行次数是不同单位；同请求的decode steps通常相互依赖。
